# Сайт Любови Мальцевой

Статический сайт: HTML, CSS и небольшой JavaScript. Сборка, npm и серверная часть не нужны. Публикация совместима с GitHub Pages.

## Локальный просмотр

Из каталога репозитория:

```sh
python -m http.server 8088 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8088.

## Где что менять

- `index.html` — содержание, цены, контакты, метаданные и порядок разделов.
- `style.css` — палитра в `:root`, базовая мобильная вёрстка и расширения для планшетов/компьютеров.
- `script.js` — раскрытие мобильного меню, управление фокусом, нижняя мобильная кнопка, год в подвале.
- `assets/` — адаптивные WebP-фотографии. Исходные PNG сохранены для запасного формата и дальнейшей обработки.
- `DESIGN-REVIEW.md` — анализ исходной версии, принятые решения и результаты проверки.

Номер меняется в `index.html` (поле `contact-phone`) и `script.js` (значение для копирования). Кнопки записи ведут к контактам внутри страницы. Внешних переходов в мессенджеры нет. Подпись перечисляет MAX / WhatsApp / Telegram; посетитель копирует номер и открывает нужное приложение самостоятельно.

Основное содержание, номер для связи и FAQ доступны без JavaScript. Аналитики, форм отправки, cookie и localStorage в новой версии нет. Шрифты системные, изображения локальные; внешние сервисы не нужны для отображения страницы.

## Перед публикацией изменений

Проверить локальную версию на телефоне и компьютере. Команда `node --check script.js` проверяет синтаксис JavaScript. Убедиться, что все четыре WebP-файла из `assets/` включены в коммит вместе с HTML/CSS/JS.

Развёртывание выполняется через существующие настройки GitHub Pages репозитория. В рамках переработки изменения подготовлены локально, без push.
