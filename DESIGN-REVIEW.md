# Разбор и переработка сайта

Дата: 18 сентября 2026 года.

## Задача

Сделать личный сайт психолога удобным прежде всего на телефоне: быстро познакомить со специалистом, объяснить процесс, показать стоимость и дать понятный способ связаться. Визуальный характер — спокойный, личный и профессиональный.

## Что мешало в исходной версии

1. **Нарушенная иерархия первого экрана.** На 390 px портрет и вводный текст находились перед главным заголовком. Имя и квалификация размещались поверх затемнённой фотографии. Первая содержательная кнопка предлагала узнать больше, а не начать знакомство.
2. **Конкурирующие эффекты.** Canvas с движущимися кругами, свечение, бегущая строка, параллакс, нестандартный курсор, анимации появления и смена палитры одновременно привлекали внимание.
3. **Десктопная композиция на мобильном.** Глобальный `min-height: 100vh` для разделов, крупная типографика и большое количество декоративных элементов увеличивали длину страницы без дополнительной пользы.
4. **Риск ошибки в сетке стоимости.** На узком экране задавалась одна колонка, но у цены сохранялось `grid-column: 2` из предыдущего правила. Это могло создавать неявную вторую колонку.
5. **Непрозрачный переход к записи.** Ссылка с подписью MAX / WhatsApp / Telegram использовала `tel:` и запускала звонок. Отдельная рабочая Telegram-ссылка была в меню.
6. **Проблемы доступности.** Выбор темы через маленькие `div`, скрытый стандартный курсор, слабый визуальный контраст текста поверх декораций. Отключение CSS-анимаций не останавливало canvas-цикл.
7. **Лишние зависимости и код.** Внешние шрифты и текстура; код имитации отправки формы, которой не было в HTML; cookie-баннер для локального флага согласия. Невалидное `opacity(0)` внутри `transform`, лишний закрывающий `div` в первом экране.
8. **Содержание было абстрактным.** Длинное объяснение гештальта предшествовало практическим условиям. Некоторые формулировки звучали как обещание результата. Статистика о клиентах и стаже без даты быстро устаревает.

## Принятые решения

### Путь посетителя

Знакомство и прямое действие → узнаваемые запросы → специалист и образование → краткое объяснение подхода → процесс первой встречи → форматы и стоимость → вопросы → контакты.

Навигация позволяет сразу перейти к стоимости. Кнопка первого экрана ведёт прямо в Telegram. В середине страницы на телефоне появляется дополнительная кнопка; у первого экрана, открытого меню и блока контактов она скрыта.

### Визуальная система

Молочный фон, тёмный текст, один оливковый акцент. Выразительная антиква для заголовков, простой системный шрифт для чтения. Натуральные портреты, без наложенного на лицо текста. Секции ограничены содержанием, а не высотой экрана. Линии и отступы отделяют блоки; карточки используются там, где действительно нужно сравнение двух форматов.

Убраны бесконечные движения, смена тем, бегущая строка, магнитные эффекты и кастомный курсор. Остались короткие изменения цвета интерактивных элементов. При `prefers-reduced-motion` плавная прокрутка и переходы отключаются.

### Содержание

Сохранены имя, специализация, образование, личный терапевтический опыт, супервизия, исходные фотографии, местоположение, контакты и цены. Бесплатное знакомство — 30 минут онлайн. Индивидуальная встреча — 2 500 ₽ за 60 минут.

Объяснение подхода сокращено и переведено на повседневный язык. Убраны неподтверждённая цитата, маркетинговые счётчики и категоричные обещания исцеления. Не добавлены вымышленные отзывы, дипломы, сертификаты, адрес кабинета, свободные слоты или гарантии результата. Профессиональные сведения взяты с исходного сайта; независимой проверки квалификации не проводилось.

### Реализация

- Mobile-first CSS; расширение композиции с 700 и 1000 px, отдельные корректировки для узких экранов.
- Семантические `header`, `nav`, `main`, `section`, `footer`; один H1, последовательные уровни заголовков.
- Нативные `details/summary` для FAQ: без ограничителя высоты ответа, работают без JS.
- Мобильное меню с `aria-expanded`, Escape, возвратом фокуса и переносом фокуса в выбранный раздел.
- Видимый фокус, ссылка пропуска навигации, зоны основных действий не менее 44 px по высоте.
- Нет форм с фиктивной отправкой, аналитики, cookie, localStorage и внешних запросов шрифтов/текстур.
- Responsive WebP через `srcset`, lazy loading второй фотографии, приоритет основного портрета. Исходные PNG оставлены как fallback.
- Title, description, canonical и Open Graph для публичного адреса сайта.
- Обычный статический сайт, без нового фреймворка и обязательной сборки.

## Выполненная проверка

Проверено в браузере Chromium через локальный HTTP-сервер. Это эмуляция размеров окна, а не проверка на физическом iPhone или Android.

| Проверка | Результат |
|---|---|
| Ширины 320, 360, 390, 430, 768, 1024, 1440 px | Горизонтального переполнения и выходящих за границу элементов основного содержания не обнаружено |
| Первый экран на 320 и 390 px | Основная кнопка видна до прокрутки, заголовок читается, декоративных перекрытий нет |
| Десктопный первый экран 1440 px | Две колонки, фотография и текст визуально проверены |
| Мобильное меню | Открывается, закрывается по ссылке, `aria-expanded` обновляется |
| Escape и фокус | Меню закрывается; фокус возвращается к кнопке; переход из меню переводит фокус в раздел |
| FAQ | Открывается кликом, закрывается Enter, длинный ответ не обрезается |
| Мобильная запись | Видна в середине страницы, скрыта у hero и контактов; скрыта на планшете и десктопе |
| Изображения | Оба WebP загружаются; `alt` присутствует |
| Контактные ссылки | Telegram использует `https://t.me/malchenkolubov`, телефон использует `tel:`; сообщения и звонки не отправлялись |
| Контраст | Расчёт по вычисленным стилям отображаемых текстовых элементов: минимум 4,96:1; значений ниже порогов 4,5:1 для обычного и 3:1 для крупного текста не найдено |
| Статическая структура HTML | Вложенность тегов, уникальные ID, локальные ресурсы и цели якорей проверены |
| JavaScript | `node --check script.js` — успешно; ошибок и предупреждений страницы в журнале браузера не обнаружено |
| Git diff | `git diff --check` — без ошибок пробелов |

HTML, CSS и JS новой версии суммарно занимают около 43 КБ. Две мобильные WebP-фотографии — около 40 КБ суммарно вместо примерно 1,18 МБ исходных PNG. Фактический выбор изображения зависит от ширины и плотности пикселей устройства. Это размер файлов, а не замер скорости на мобильной сети или оценка Lighthouse.

## Границы проверки

Не выполнялись публикация, push, отправка сообщений или звонки. Не проводились тесты физического Safari/iOS, скринридера и реальной мобильной сети. Проверка контраста и семантики не является полной сертификацией WCAG. Структура сохраняет основное содержимое, FAQ и контактные ссылки без JavaScript; отдельный браузерный прогон с отключённым JavaScript не выполнялся.


## Последующая правка: номер и портрет

По просьбе владельца внешние переходы в Telegram и телефонный вызов заменены номером с иконкой копирования. Кнопки записи ведут к блоку контактов. Подпись: MAX / WhatsApp / Telegram. Clipboard API вызывается только по нажатию; предусмотрены резервное копирование выделенного номера и понятная инструкция при отказе браузера. Номер остаётся доступен для ручного выделения без JavaScript. Предыдущие результаты проверки внешних ссылок выше относятся к первой итерации дизайна.

Первый портрет заменён обработанным вариантом, созданным встроенным imagegen по двум исходным фотографиям. Вторая фотография использована как ориентир реальной внешности. Это редактирование изображения, а не восстановленная необработанная фотография. Второй портрет на сайте не изменён. Исходные изображения сохранены. Полный промпт и файлы результата описаны в `assets/PORTRAIT-EDIT.md`.
